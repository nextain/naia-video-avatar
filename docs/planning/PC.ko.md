## 1. 제품 정의 및 대상 사용자

### 1.1 NVA의 정의
**NVA(naia video clip avatar)**는 브라우저에서 GPU 추론이나 무거운 런타임 없이 투명하게 재생할 수 있는 ZIP 기반 비디오 아바타 포맷이자 독립 플레이어다. 사전 렌더링된 비디오 클립을 표준 HTML5 비디오 디코딩으로 직접 재생하여 클라이언트 브라우저에서 가볍고 안정적으로 동작한다.

### 1.2 대상 사용자
- **웹 서비스 개발자 및 프론트엔드 엔지니어**: GPU 서버 인프라를 운영하지 않고도 웹 대시보드, 키오스크, 모바일 웹 앱, 디지털 사이니지에 대화형 투명 아바타를 삽입하려는 팀.
- **콘텐츠 제작자 및 파이프라인 엔지니어**: 정적 콘텐츠 전송망(CDN)을 통해 결정론적 패키징 도구로 제작된 발화 아바타를 배포하려는 팀.
- **보안 및 독립 폐쇄망 환경**: 외부 네트워크 접근, API 키 전송, 서버 사이드 실시간 비디오 스트리밍이 차단된 오프라인 환경.

## 2. 시스템 구성

이 저장소는 다음 세 가지 핵심 구성요소로 이루어진다:

1. **NVA 포맷 규격 (v0.3 completed-media)**:
   - 선언적 메타데이터(`manifest.json`), 비디오 클립(`clips/`), 음성이 내장된 완성 발화 영상(`speech/`)을 담는 표준화된 ZIP 아카이브 레이아웃.
   - 상세 규격: [NVA 포맷 가이드](../nva-format-guide.ko.md).
2. **읽기 전용 웹 Player**:
   - 외부 라이브러리 의존성 없이 순수 자바스크립트 ES 모듈로 구현된 경량 플레이어(`src/main/viewer.html` 및 모듈들).
   - 대기 영상(idle) 무음 루프, 액션 재생, 음성이 포함된 발화 영상 재생, 정지 및 오류 발생 시 대기 상태 복귀를 관리.
3. **공개 예제 및 검증 도구**:
   - 브라우저 검증 및 회귀 테스트를 위한 최소 공개 예제(`examples/demo.nva`, `examples/naia.nva`).
   - 결정론적 패키징 스크립트(`scripts/build-final-nva.py`) 및 로컬 샘플 준비 스크립트(`scripts/prepare-local-samples.py`).

## 3. 소유권 경계

저작 시스템(Studio)과 재생 시스템(Player)의 역할과 소유 범위를 명확히 분리한다:

```text
┌──────────────────────────────────┐       ┌──────────────────────────────────┐
│      Naia Studio (저작·생성)     │       │    naia-video-avatar (검증·재생) │
│  - 얼굴 합성 및 비디오 렌더링   │       │  - 매니페스트 스키마·경로 검증   │
│  - TTS 음성 합성 및 오디오 생성  │ ──►   │  - 무의존성 ZIP 로더             │
│  - 실시간 립싱크 모델 추론       │ .nva  │  - 읽기 전용 웹 Player           │
│  - 저작 에디터 UI                │       │  - 결정론적 패키징 도구          │
└──────────────────────────────────┘       └──────────────────────────────────┘
```

- **이 저장소의 범위 (In-Scope)**:
  - 매니페스트 스키마, ZIP 번들 경로 안전성, 미디어 안전성 검증.
  - 브라우저 클라이언트 측 안전한 ZIP 파싱 및 Object URL 수명주기 관리.
  - 브라우저 재생 제어: 대기 영상, 액션 영상, 말하기 루프, 발화 영상, 정지 처리.
  - 반응형 아바타 프리뷰 및 배경 합성 UI.
- **저장소 밖의 범위 (Out-of-Scope)**:
  - 아바타 이미지 생성, 표정 합성, 모델 추론 비디오 렌더링.
  - 텍스트 음성 변환(TTS) 및 음성 파형 생성.
  - 실시간 립싱크 추론 및 인공신경망 모델 구동.
  - 저작용 에디터, 노드 그래프 조작, 비공개 작업공간 거버넌스.

## 4. 불변 원칙

1. **v0.3 completed-media 정본 원칙**:
   v0.3 패키지의 모든 발화 영상은 사전에 영상과 음성이 결합된 완성형 미디어여야 한다. Player는 미디어를 디코딩해 재생할 뿐 음성을 합성하거나 실시간 모션을 생성하지 않는다.
2. **v0.2 읽기 호환 원칙 (NFR-011)**:
   Player는 기존 Studio 0.2 번들(말하기 루프 `talking`, 액션 목록, `locale` 별칭)의 읽기 재생을 지원하되, 저작 및 생성용 필드는 무시하며 canonical v0.3 산출물에 포함하지 않는다.
3. **외부 실행 코드 배제 원칙**:
   NVA 번들은 선언적 미디어와 메타데이터로만 구성된다. 로더는 ZIP 파일 목록에 절대경로, URL 스킴, 역슬래시, `.`/`..` 경로 조각이 있으면 번들을 거부하고 크기 제한(압축본과 해제 자산 100 MiB, 매니페스트 1 MiB, 파일 512개)을 적용한다. Player는 번들 내용을 실행하지 않으며 매니페스트가 참조하지 않는 파일은 재생하지 않는다.
4. **런타임 외부 네트워크 의존성 0 원칙**:
   파일 로드 완료 후 Player는 외부 CDN, 네트워크 API 호출, 폰트 다운로드, 원격 텔레메트리 없이 로컬에서 완결되어 동작한다.
5. **보안 및 검증 무결성**:
   보안 경계는 [위협 모델](../threat-model.ko.md)을 준수하며, 검증 판정은 [합격 기준](../acceptance-criteria.ko.md)의 기계 검증 원칙을 따른다.

## 1. 화면 개요

`SP-01 Player`는 패키징된 NVA 아바타 파일을 브라우저에서 열고, 배경 무대 위에서 투명 비디오를 재생하며, 발화 영상·말하기 루프·액션 클립을 제어하는 단일 화면 웹 플레이어 인터페이스다.

---

## 3. 조작 및 상태 변화

| 조작 요소 | DOM 셀렉터 | 조작 트리거 | 상태 변화 및 동작 |
|---|---|---|---|
| **파일 열기** | `input#nvaFile[type=file]` | 로컬 `.nva` / `.zip` 파일 선택 | 1. `LoadCoordinator.begin()`으로 새 세대를 열고 이전 로드를 취소.<br>2. 재생 버튼 비활성화, `#status`에 `"Loading <파일명>…"` 표시.<br>3. `loadNvaBundle()`로 ZIP 파싱 및 스키마 검증.<br>4. 비디오 종횡비를 캔버스 비율로 설정.<br>5. 대기 영상(idle) 무음 루프 재생 시작 (`muted=true`, `loop=true`, `state="idle"`).<br>6. 발화·액션 드롭다운 구성 및 버튼 활성화.<br>7. `#status`에 `"Ready · <이름> · N개 발화 영상 · N개 액션"` 표시. |
| **샘플 메뉴** | `select#sample`<br>`button#loadSample` | 카탈로그 항목 선택 후 버튼 클릭 | `fetchNvaSample()`을 통해 동일 출처 카탈로그에서 번들을 가져와 파일 열기와 동일한 수명주기로 로드. |
| **배경 색상** | `input#backgroundColor[type=color]` | 색상 변경 (`input` 이벤트) | `stageBackground.setColor()`를 통해 `#stage` 배경색을 실시간 변경. |
| **배경 이미지** | `input#backgroundImage[type=file]` | 로컬 이미지 파일 선택 | Blob URL을 생성하고 이전 URL을 해제한 뒤 `#stage` 배경 이미지로 지정. |
| **배경 초기화** | `button#clearBackground` | 버튼 클릭 | 배경 이미지를 제거하고 지정된 단색 배경으로 복원. |
| **발화 영상** | `select#speechClip`<br>`button#playSpeech` | 클립 선택 후 버튼 클릭 | 음성을 켜고 1회 재생 (`muted=false`, `loop=false`, `state="speech"`). 재생 종료 시 자동으로 무음 대기 영상으로 복귀하며 `"Playback complete; idle restored."` 표시. |
| **말하기 루프** | `button#playTalking` | 버튼 클릭 | Studio 0.2 번들에 말하기 루프(루프형이고 전환이 아니며 `can_talk` 속성을 가진 애니메이션. 시나리오 시작 애니메이션 우선, 없으면 매니페스트 순서상 첫 번째)가 있을 때 활성화. 무음 루프 재생 (`muted=true`, `loop=true`, `state="talking"`). `#status`에 `"Playing talking loop."` 표시. |
| **액션 재생** | `select#action`<br>`button#playAction` | 액션 선택 후 버튼 클릭 | 무음 1회 재생 (`muted=true`, `loop=false`, `state="action"`). 클립 종료 시 자동으로 무음 대기 영상 복귀. |
| **소품 동작 재생** | `select#action`<br>`button#playAction` | 소품 동작 선택 후 버튼 클릭 | 액션 드롭다운에 단일 항목으로 노출. 복합 순서(enter 1회[있을 때] → 본 동작 2회 → exit 1회[있을 때])로 연속 재생. 중간 단계에서는 완료 문구를 띄우지 않으며, 마지막 단계 종료 시 자동으로 무음 대기 영상 복귀. |
| **정지** | `button#stop` | 버튼 클릭 | 진행 중인 발화·말하기 루프·액션을 즉시 중단하고 무음 대기 영상(`state="idle"`)으로 복귀. `#status`에 `"Stopped; idle restored."` 표시. |

## 4. 오류 표시 및 복구

모든 오류는 `#status` 영역에 적색 텍스트(색상 `#ff8d8d`)로 표시된다:
- **매니페스트/번들 검증 오류**: `"Blocked: <사유>"` 표시. 모든 재생 컨트롤(발화·액션 선택기, 재생 버튼 3개, 정지 버튼)은 비활성화되고, 이전에 로드된 아바타는 무대에서 제거된다.
- **발화 영상 재생 실패**: 대기 상태로 복귀 후 `"Speech video failed: <사유>"` 표시.
- **말하기 루프 실패**: 대기 상태로 복귀 후 `"Talking failed: <사유>"` 표시.
- **액션 클립 실패**: 대기 상태로 복귀 후 `"Action failed: <사유>"` 표시.
- **샘플 카탈로그 로드 차단**: `"Sample catalog blocked: <사유>. You can still open a local file."` 표시. 로컬 파일 열기 기능은 정상 유지.

## 5. 지원 유저 시나리오 (UC)

이 화면 기획은 다음 유저 시나리오를 충족한다:
- `UC-001`: completed-media 매니페스트 및 번들 안전성 확인
- `UC-002`: NVA 파일 로드 및 기본 대기 영상 표시
- `UC-013`: 음성이 포함된 완성 발화 영상 재생 및 정지 복귀
- `UC-014`: 액션 영상 재생 및 대기 복귀
- `UC-015`: 동일 출처 카탈로그 기반 샘플 선택
- `UC-017`: GPU/외부 API 없는 독립 브라우저 재생
- `UC-019`: 대화형 배경 색상 및 이미지 합성
- `UC-020`: Studio 0.2 하위 호환 (말하기 루프 및 액션 재생)
- `UC-021`: Studio v0.2 소품 동작 순서를 단일 액션으로 복합 재생

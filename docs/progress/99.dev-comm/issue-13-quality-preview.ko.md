## 2026-08-02 결론 업데이트 — 512 전체 ROI

Jina의 Ditto 입력은 얼굴만 자른 영상이 아니라 머리·목·어깨 위쪽을 함께 담은 512×512 ROI다. 따라서 하관만 추출한 이전 A/B 방식은 Ditto가 함께 생성한 코·볼·턱·목 움직임을 잘라 고정 영역과 충돌시켰다. **하관 발화층 방식은 폐기하고 512 ROI 전체 조각을 사용한다.** 아래의 기존 하관 결과는 의사결정 과정 보존용이며 현재 설계가 아니다.

실제 VoxCPM2 한국어 문장으로 전체 ROI 조각 13개를 독립 생성해 재조합했다.

> 안녕하세요. 나이아 비디오 아바타의 실제 조합 발화 품질을 확인합니다.

모든 영상은 25fps, 4.48초이고 같은 한국어 음성을 사용한다. R 영상은 실제 오디오를 1.2초 겹침 창으로 잘라 각 창을 Ditto에 독립 입력하고 중앙 11프레임을 사용했다. 이 방식은 전체 ROI 컷 연속성을 확인하는 실험이며 아직 재사용 가능한 13단위 atlas는 아니다.

|---|---:|---:|---:|---|
| 무정렬, 80ms | 0.3573 | 0.1699 | 0.98874 | 컷이 큼 |
| 무정렬, 160ms | 0.2341 | 0.1212 | 0.98876 | 개선 |
| 무정렬, 240ms | **0.1675** | **0.1165** | **0.98885** | 현재 최선 |
| 프레임별 유사변환 | 1.7902 | 0.9949 | 0.96245 | 폐기 |
| 조각별 유사변환 | 1.6288 | 1.1335 | 0.95916 | 폐기 |
| 조각별 평행이동 | 2.0223 | 1.2262 | 0.95515 | 폐기 |

최종 240ms 후보는 같은 실행에서 디코딩한 W와 R의 동일 전환 시점을 다시 비교했다. 인접 프레임 최대 변화는 W 0.16490, R 0.16456이었고 R의 추가 변화는 -0.00034였다. 따라서 이 표본에서는 교차 전환 자체가 원본보다 큰 순간 점프를 만들지 않았다. 전체 화면 SSIM은 0.98883이지만 정적인 몸이 점수를 높이므로, 발화 영역 SSIM 0.68007과 머리 중 발화 영역 밖 SSIM 0.97999를 함께 본다.

공간 정렬은 얼굴 기준 변환을 목·어깨까지 포함한 ROI 전체에 적용하면서 오히려 접합을 크게 악화시켰다. 생성 후 정렬은 사용하지 않는다. 현재 최선은 **무정렬 512 전체 ROI + 240ms 교차 전환**이다. 하관 절단과 추가 순간 점프는 이 표본에서 사라졌지만 W와 R의 발화 움직임 궤적은 아직 다르므로 제품 합격은 아니다. 다음 생성기는 각 조각을 사후 변형하지 않고 Ditto 입력의 준비 문맥과 시작·끝 동작을 고정해야 한다.

- 독립 검토 도구는 Gemini 계정 지원 종료와 Claude 실행 오류로 완전한 다중 검토에 이르지 못했다. 이를 CLEAN으로 계산하지 않았으며, 직접 적대 검토에서 누락된 전체 ROI 불투명도 테스트를 추가했다.
- 제품 보존 판정은 `REVIEW_ONLY`다. 이번 변경은 탐색 검사기와 문서만 추가했으며 공개 Player의 하관용 계약은 아직 전체 ROI 계약으로 바꾸지 않았다.

## 이전 하관 실험 기록 — 현재 설계 아님

실제 Jina와 실제 Ditto를 사용해 여섯 개 발화 전환 조각을 독립 생성하고 다시 이어 붙이는 경로는 동작했다. 입 주변만 제한적으로 바꾸므로 눈·머리카락·머리 자세가 컷마다 흔들리는 문제는 차단했고, 눈 영역 오염과 지정 영역 밖 알파도 0이었다.

초기 5프레임 pair 조각은 발화 접합 영역 SSIM 0.6616, PSNR 19.29dB로 제품 합격 수준이 아니었다. 후속 2×2 실험에서 하안면 저주파 보정층은 전환 불안정을 키워 폐기했고, 11프레임만 사용하는 편이 나았다. 가장 큰 개선은 Ditto 생성 시 바로 앞 단위만 주는 대신 `이전이전→이전→현재` 3단위 문맥을 보존했을 때 나왔다. 최신 후보는 발화 접합 영역 SSIM 0.7783, PSNR 22.10dB이며 전환 최대 변화량은 기준과 같은 0.0710 수준이다. **방향성은 확인했지만 아직 제품 합격은 아니다.** 공식 판정은 `INCONCLUSIVE`, 3단위 문맥 후보는 `PROMISING_NEEDS_MULTILINGUAL_VALIDATION`이다.

## 구현된 실제 경로

```text
고정 발화 단위 오디오
  → 실제 Ditto TRT 렌더
  → 이전이전>이전>현재 문맥별 11프레임 추출
  → 중립 Jina와의 차이에서 입 주변 투명 발화층 생성
  → 음성 시계에 맞춰 조각 소유권 전환
  → 80ms 완만한 코사인 혼합
  → Jina 몸 영상 위에 합성
```

공개 NVA에는 Ditto나 GPU 코드가 들어가지 않는다. 공개 Player는 NVA 안의 조각과 SpeechPlan만 읽는다. 실제 Ditto 실행, 얼굴 원본, 품질 분석은 비공개 Naia 생성 서비스가 담당한다.

이번에 비공개 생성 서비스에 추가한 `output_cascade/ditto_quality_probe.py`는 위 경로를 반복 실행할 수 있다. 가짜 영상이 아니라 현재 실행 중인 Ditto TensorRT 서비스에 실제로 요청하며, 전체 발화와 독립 pair 전환을 각각 새로 렌더한다. 조합 영상은 FFV1 무손실 중간 영상을 거쳐 최종 H.264로 한 번만 손실 압축하므로 F 쪽에만 중복 압축 손실이 생기지 않는다.

## 영상을 볼 때 확인할 것

1. 모음이 바뀌는 순간 입이 한 프레임 만에 튀는가?
2. 입술 주변에 밝기 테두리나 피부색 경계가 보이는가?
3. 턱이 움직일 때 고정된 볼·목과 부딪혀 고무처럼 보이는가?
4. 오른쪽 F에서 눈과 머리카락은 안정적인데 표정이 너무 죽지는 않는가?
5. 왼쪽 W보다 오른쪽 F의 입 모양이 음성에서 늦거나 너무 작게 느껴지는가?

현재 접촉 시트만으로 큰 전신 점프를 찾기는 어렵다. 반면 영상과 접합 영역 수치는 F가 W보다 입·볼·턱의 표현 폭을 크게 잃는다는 점을 보여 준다. 이것이 컷 안정성과 자연스러운 표정 사이의 핵심 절충점이다.

## 다음 판정 단계

1. 13개 공통 발화 단위의 169개 pair를 fallback으로 만들고, 다국어 코퍼스 빈도가 높은 3단위 문맥을 제한된 추가 슬롯으로 선정한다.
2. VoxCPM2 음성을 다국어 강제 정렬기(MFA)로 정렬해 SpeechPlan이 3단위 문맥을 우선 선택하고 없으면 pair로 내려가게 한다.
3. 한국어·영어·일본어·중국어 각 20문장을 전체 발화 Ditto와 조합 영상으로 만들어 입 동기화와 블라인드 자연스러움을 평가한다.
4. Jina가 통과한 뒤 같은 표현 방식과 기준을 Naia 고양이형에 별도 적용한다.

현재 권고는 **512 전체 ROI를 사후 공간 변형 없이 유지하고, 240ms 교차 전환을 컷 연속성 기준 후보로 채택하는 것**이다. 이 한국어 문장 실험은 자연 음성 창을 다시 사용한 컷 검사이지 재사용 가능한 발음 atlas 검사가 아니다. 다음 단계는 동일한 전체 ROI 표현으로 시작·끝 상태가 고정된 재사용 단위를 생성해 W와 비교하는 것이다. 사람형 Jina의 다국어 문장 평가가 통과하기 전에는 Naia 고양이형을 제품 근거로 사용하지 않는다.

## 2,197개 품질검사 방법

모든 조각을 사람이 재생하지 않는다. 전체 조각은 디코딩, 프레임 수, FPS, SHA-256, 눈 침범, 영역 밖 알파, 전환 변화량, 접합선 에너지, 머리 이동과 입 운동량을 자동 검사한다. 검사기는 구조적 실패를 닫힌 상태로 차단하고 이상치 점수를 계산한다.

사람은 자동 선정된 최악 50개와 결정론적 무작위 50개를 보고, 별도로 한·영·일·중 실제 문장 조합 영상을 평가한다. 자동검사만 끝난 상태는 `screened`이며 자연스러움 합격으로 표시할 수 없다. 불량 조각은 atlas 전체가 아니라 해당 키만 재생성한다.
